## 1단계: 다른 PC 코드 확보 (가장 중요)

아래 중 **하나**를 먼저 하세요.

### 방법 A — 다른 PC 프로젝트 폴더 복사 (가장 확실)

1. 다른 PC의 `tax-analyzer` 폴더 전체를 USB / 공유 폴더 / zip으로 이 PC에 받기  
2. 예: `C:\Users\찰리\Desktop\tax-analyzer-other-pc\`  
3. **종합소득세만** 비교할 파일:
   - 다른 PC가 `app/page.tsx`면 → 이 PC `app/tax/comprehensive/page.tsx`와 비교
   - 다른 PC도 `app/tax/comprehensive/page.tsx`면 → 그 파일끼리 비교

### 방법 B — Vercel 대시보드에서 소스 받기

1. 다른 PC에서 쓰던 **Vercel 로그인 계정**으로 [vercel.com](https://vercel.com) 접속  
2. **tax-analyzer**(또는 해당) 프로젝트 → **Deployments** → **Production** 배포 선택  
3. **Source** / **Download** / 연결된 Git 커밋 확인  
   - Git 연결 없이 CLI만 썼다면: **Visit** 옆 메뉴에서 소스 다운로드 가능 여부 확인  
4. 배포 URL 예: `https://프로젝트명.vercel.app`

### 방법 C — 다른 PC에서 Git으로 올리기 (앞으로 권장)

다른 PC에서:

```bash
cd tax-analyzer
git init   # 아직 없다면
git remote add origin https://github.com/youth6010-sudo/tax-analyzer-.git
git checkout -b vercel-pc-updates
git add .
git commit -m "chore: other PC Vercel version snapshot"
git push -u origin vercel-pc-updates
```

이 PC에서:

```bash
git fetch origin
git merge origin/vercel-pc-updates
# 또는 diff만 보기: git diff main origin/vercel-pc-updates -- app/
```

## 4단계: Vercel을 Git 기준으로 통일

앞으로 **Git push = 배포** 한 줄로 맞추는 것을 권장합니다.

1. [vercel.com](https://vercel.com) → **Add Project** → GitHub `youth6010-sudo/tax-analyzer-` 연결  
   - 이미 프로젝트가 있으면 **Settings → Git** 에서 같은 저장소 연결  
2. **Production Branch:** `main`  
3. **Root Directory:** `.` (저장소 루트가 tax-analyzer이면 그대로)  
4. `main`에 push하면 자동 배포  

### 이 PC에서 CLI 연결 (선택)

```powershell
cd C:\Users\찰리\Desktop\tax-analyzer
npx vercel@latest login
npx vercel@latest link
# 팀·프로젝트 선택
npx vercel@latest --prod   # Git push 대신 수동 배포할 때만
```

## 6단계: 앞으로 동시에 두 PC에서 작업할 때

1. **항상 Git을 거친다** — `pull` → 작업 → `push`  
2. Vercel CLI `--prod`만 다른 PC에서 따로 쓰지 않는다  
3. 종합소득세 큰 수정 전 **작업저장 JSON**  
4. 거래처 대량 수정 전 **`contacts.json` 백업**

1. **다른 PC**에 연락 → 프로젝트 폴더 zip 또는 `vercel-pc-updates` 브랜치 push  
2. 이 PC에서 **종합소득세 파일 diff** 후 `app/tax/comprehensive/page.tsx`에 반영  
3. **작업저장 JSON** + **contacts.json** 백업

5. Vercel을 GitHub `main`과 연결 → Production 배포 확인

## 문제 발생 시

| 증상 | 조치 |
|------|------|
| 다른 PC 코드를 모름 | 방법 A로 폴더 받기 |
| merge 충돌 | `app/tax/comprehensive/page.tsx`, `contacts.json` 수동 정리 |
| Vercel에 tax-analyzer가 안 보임 | 다른 PC Vercel 계정으로 로그인 |
| 배포 후 종소세 입력 사라짐 | localStorage 키 변경 여부 확인 → JSON import |
| 거래처 수정이 배포 후 사라짐 | `contacts.json`을 Git에 커밋했는지 확인 |
