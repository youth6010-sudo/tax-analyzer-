## 1. 고정되는 것 (올리지 않아도 / 올려도 유지)

### ① 공문 cutoff — `2026.08.31`
- 이 날 **포함·이전** 공문 상세는 동결(복잡미수).
- 거래처별 엑셀을 올려도 **9월~ 거래만** 공문에 추가.
- 7·8월 기장·입금을 업로드가 지우거나 다시 조립하지 **않음**(기장료만 제외).

### ② 기장료만 vs 복잡미수
| 구분 | 조건 | 업로드 시 |
|------|------|-----------|
| **기장료만** (`simple_bk`) | 미수가 기장·기타수수료만, **미납 월 ≤ 1**이고 그 달이 **가장 최근 청구월** (예: 태평푸드 8월분) | 업로드 때 기존 줄에 새 거래를 붙이고 입금은 전월 기장료 옆에 붙임. 최근 월만 미납이면 미납 줄만 남겨 **롤링**(월이 바뀜). **중간에 한 달이라도 미납**이 생기면(2개월↑ 미납, 또는 미납 월 뒤에 청구가 더 있음) **전부 공문에 남김** → 이후 복잡미수 |
| **복잡미수** (`complex`) | **2개월↑** 기장 밀림, **조정료·성실·부가세** 등 포함, 또는 **미납 월 뒤에 청구가 더 있음** (예: 수헤어룸 — 7월분부터 미수 시작, 이후 차월 입금) | **지금 고정값 유지** + 9월~ 기장료·입금 **계속 추가** |
| **보호** | 오프라인·하나비 (인디, 수동으로 맞춘 공문) | 거래처별 자동 반영 **제외** |
| **내용 동결** | 에스와이·한빛·로터스·올바릇 4곳 | 기장료와 같은 금액의 입금·그 청구는 **안 넣고 차이로**, 그 외 입금·청구는 **추가** |

분류·스냅샷: `lib/arrearsLetterComplexity.ts` · `data/arrears-content-frozen-codes.json` · `data/arrears-frozen-letter-lines.json`  
재스냅샷: `node --import tsx scripts/freeze-today-arrears-letters.mjs --apply`

### ③ 저번주~오늘 확정한 표시 규칙 (코드)
- **법인조정료 등**: 공문 원문 유지. asOf 연도 임의 부착 금지.
- **기장 사이에 낀 조정·성실**: 화면에서 연도 숨김 가능.
- Neon(`PREV`)으로 공문 **통째 덮어쓰기 금지**.

### ④ 예외 업체 (코드에 박힘)
| 코드 | 상호 | 동작 |
|------|------|------|
| 00130·00131·00229 | 티밸류홀딩스·매거진·예윤 | 잔액=공문합이어도 **불일치(원장)** 강제 |
| **00183**·00199 | **오프라인**·하나비 | 인디 업체. 외부잔액 ≠ 상세내역이라 공문을 수동으로 맞춤. 거래처별 자동 반영 **제외** |
| **00176** | **에스와이메탈** | 지정 공문 유지(선수금 대체 22만 포함). 기장료 청구·입금은 안 넣음. **기장료 외 입금은 추가** |
| **00191** | **한빛이텍** | 빈 지급 100만 + 7·8월 기장 **내용 동결**. 입금 없는 기장료 청구는 계속 추가 |
| **00152** | **로터스인베스트먼트** | 07.27 공문 전체 + 7·8월 **내용 동결**. 입금 없는 기장료 청구는 계속 추가 |
| **01206** | **올바릇** | 7/31 300만(기장료 외 입금) 유지. **9/15 24.2만(차월 기장료 입금)은 공문 제외** → 현황과 **불일치** |
| 담당=인디 | — | 현재 거래 없음 → 거래처별 파일 **반영 안 함**. 잔액만 현황표, 상세는 기존 공문 |

**내용 동결 4곳 업로드 규칙** (`dropDeferredBookkeepingTxs`)
1. 기장료 청구 + 같은 금액 입금 세트 → 둘 다 공문에 안 넣음
2. 남은 입금 중 기장료와 같은 금액(차월 입금) → 안 넣음 → 현황과 **차이로 표시**
3. 입금이 아직 없는 기장료 청구 → 추가 (한빛·로터스처럼 안 내는 곳은 계속 쌓임)
4. 기장료 외 입금(예: 조정료 100만)·기장료 외 청구 → **추가**
- 기장료 금액 = 거래처별 파일의 「N월 기장」청구 금액 + 공문 월기장 줄 금액

수동 확정분 복구: `node --import tsx scripts/ensure-frozen-letter-patches.mjs --apply`  
기준 파일: `data/arrears-frozen-letter-patches.json` · 스냅샷 `data/arrears-frozen-letter-lines.json`

### ⑤ 불일치 판정 공식 (고정)
```
불일치 = 현황표 잔액 ≠ 공문 Σ(금액 − 지급)
```
잔액 **음수**이고 상세합 0이면 「원장만」(세부 없음).  
가짜 줄(`미수반영(현황맞춤)`)로 맞추지 않음.

## 2. 업로드하면 바뀌는 것

화면: **미수관리 → 엑셀 업로드 → 두 파일 함께 반영**  
파일명: `미수수수료 거래처(잔액)현황_날짜` + `거래처별 현황_날짜`

### ① 현황표 (잔액 파일)
| 바뀜 | 안 바뀜 |
|------|---------|
| DB **잔액**·이월·차대 | 공문 줄 |
| 기준일(`statusAsOfDate`) | cutoff(항상 8/31) |
| 담당(수임처 미연결 시만) | 수임처 연결된 담당 |

### ② 거래처별 현황
| 바뀜 | 안 바뀜 |
|------|---------|
| **9월~** 기장·입금 줄 추가/교체 | **8월까지** 공문 전체(복잡미수) |
| 기장료만: 월 롤링 재구성 | 수정모드 **manual** 줄 |
| | 인디(오프라인·하나비 포함) |
| | 내용 동결 4곳의 기장료 청구·입금 |

추가 규칙:
- 공문에 **기장 미납이 한 달이라도 있으면** → 매출·입금 쌍을 생략하지 않음.
- 기장 미납이 **없으면** → 같은 달 매출+입금 즉시회수 세트는 공문에 안 넣음.
- **월 기장료 + 지급**은 6월처럼 **한 줄**(금액·지급·지급일)로 저장 (`mergeMonthlyBookkeepingPaymentRows`).
- **올바릇(01206)**: 기장 미수 없음 → **9/15 24.2만 입금은 공문에서 제외**, 현황과 불일치로 표시.

## 6. 일시미수·월기장 입금은 어떻게 되나?

### 관리분류「일시」
- 잔액 ≥ 월기장×2 이면 자동으로「일시」표시.
- **잔액 0**이 되면 분류만 미분류로 되돌림. (공문 줄을 이 때문에 지우지는 않음)

### 공문 내역 (업로드 기준)
| 상황 | 동작 |
|------|------|
| **복잡미수** (조정료 있거나 기장 2개월↑) | **8/31까지 줄 고정**. 9월~ 거래만 **뒤에 추가**. 다음달 기장 입금은 해당 월 줄에 지급만 붙음(한 줄). **회수돼도 과거 줄은 DB에 남음**(화면은 현재 사이클만 보이기도 함). |
| **기장료만·미납 1개월** (일시성) | 업로드 시 월이 **롤링**될 수 있음(옛 월 줄 교체). 다음달 입금 = 그 월 기장 옆에 붙음. |
| **같은 달 기장+입금 즉시회수** | 공문에 **안 넣음**(미수가 아니므로). |
| **잔액 0으로 맞춘 뒤** | 예전에 잔액0 업체 공문을 비운 상태가 있음. 이후 **새로 미수가 생기면** 9월~ 업로드분부터 다시 쌓임. 0원 된「빈 줄」에 이어 붙이지 않음. |

정리: **밀린 미수에 입금되면 → 그 내역 줄에 지급이 붙음(연결).**  
**애초에 미수가 안 된 달(당월 완납)은 공문에 안 올라감.**  
**다 갚아서 잔액 0이 된 뒤 다시 미수가 생기면 → 새 구간으로 반영**(과거 0원 이력에 억지로 이어 붙이지 않음).
