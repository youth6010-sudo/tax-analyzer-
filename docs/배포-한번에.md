# 한 번에 웹으로 쓰기

## A. PC에서만 — 링크로 들어가기 (가장 쉬움)

1. **Node.js 20** 이상 설치: https://nodejs.org  
2. **`시작.bat`** 또는 **`시작하기.bat`** 더블클릭 → 약 8초 뒤 브라우저가 **http://localhost:3000** 으로 열립니다.  
3. 서버를 이미 켜 둔 뒤에는 **`로컬에서열기.url`** 만 더블클릭하면 같은 주소로 들어갑니다. (인터넷 바로가기 파일이라 `cmd` 한글 문제 없음)

---

## B. 고정 주소(영구) — Vercel (한 번만 설정)

제가 대신 로그인할 수는 없어서, **처음 한 번만** 아래를 해 주셔야 합니다. 이후는 `git push`만 하면 자동 배포됩니다.

### 1) GitHub에 코드 올리기

- [GitHub](https://github.com)에서 새 저장소를 만듭니다.
- 이 `tax-analyzer` 폴더 내용을 그 저장소에 올립니다. (GitHub Desktop이나 웹 업로드로도 됩니다.)

### 2) Vercel에서 프로젝트 만들기

1. [vercel.com](https://vercel.com) 가입 후 **Add New → Project**
2. 방금 만든 GitHub 저장소를 선택하고 **Deploy** (Root Directory가 `tax-analyzer`가 아니라 저장소 루트면 그대로 두면 됩니다.)

### 3) GitHub에 비밀번호 3개만 넣기 (자동 배포용)

Vercel → 해당 프로젝트 → **Settings → General** 맨 아래 **Project ID** 복사  
Vercel → **Settings** (팀/계정) → **Team ID** 또는 Organization ID 확인

GitHub 저장소 → **Settings → Secrets and variables → Actions** → **New repository secret**

| Name | 값 넣는 곳 |
|------|------------|
| `VERCEL_TOKEN` | Vercel → Account Settings → **Tokens** → Create |
| `VERCEL_ORG_ID` | 위에서 본 Team / Org ID |
| `VERCEL_PROJECT_ID` | 프로젝트의 Project ID |

### 4) 끝

- 이제 **`main` 브랜치에 push**할 때마다 GitHub Actions가 프로덕션으로 다시 올립니다.  
- 워크플로 파일: `.github/workflows/vercel-production.yml`
