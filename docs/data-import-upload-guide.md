# 유입·유출 업로드 안내

`청년들 ID.xlsx`의 `유입관리`·`유입프로세스`·`유출` 시트를 업로드해 미리 확인한 뒤 반영합니다. 수임처 명단(`roster`)은 변경되지 않으며, 동일 항목은 중복 없이 갱신(`upsert`)됩니다.

## 업로드 대상 시트

### 유입관리
- 문의일자
- 업체명
- 전화번호
- 유입채널
- 초회상담자
- 문의내용
- 블루홀케이스
- 특이사항
- 제안금액
- 업종
- 사업자번호
- 대표자
- 대표 연락처
- 관리자
- 관리자 연락처
- 주소
- 이메일
- 계약유무

### 유입프로세스
- 업체명
- 수수료 발생일
- 월 수수료
- 유입 경로
- 체크리스트 10개 항목
  - 계약서 작성 및 전달
  - 수임동의
  - CMS 등록
  - 담당자 배정
  - 프로그램 거래처 생성
  - 블루홀 거래처 등록
  - TP 거래처 등록
  - 위멤버스 및 세모리포트 등록
  - 사업용계좌 등록
  - 카카오방

### 유출
- 업체명
- 계약 종료일
- 수수료
- 자료 정리
- 유형
- 전조증상
- 유출 사유
- 담당자

## 반영 방식

- `유입관리`는 `excel_key` 기준으로 기존 데이터를 갱신하고, 없는 항목만 신규 추가합니다.
- `유입프로세스`는 `excel_key` 또는 업체명 기준으로 기존 데이터를 갱신하고, 없는 항목만 신규 추가합니다.
- `유출`은 기존 유출 이력이 있으면 갱신하고, 없으면 신규 추가합니다.
- 업로드 중 `client_id`는 사업자번호, 업체명, 담당자 정보를 기준으로 자동 연결됩니다.
- 프로세스만 있고 유입관리가 없는 경우에는 필요한 유입관리 항목이 자동 보완될 수 있습니다.

## 업로드 전 확인 사항

- 시트명은 반드시 `유입관리`, `유입프로세스`, `유출`이어야 합니다.
- 날짜는 가능하면 `YYYY-MM-DD` 형식으로 맞춰 주세요.
- 업체명 표기가 시트마다 다르면 자동 연결이 실패할 수 있습니다.
  - 예: `빌리언웨이브` / `빌리언웨이브 (Billion Wave)`
  - 예: `사, 여백, 찻잔` / `사,여백,찻집`
- 사업자번호, 업체명, 담당자 정보가 정확할수록 기존 데이터와 더 잘 연결됩니다.
- 담당자 이름만 있는 행이나 업체 정보가 비어 있는 행은 제외될 수 있습니다.

## 이번 파일 기준 예상 반영

- `유입관리` 64건: 신규 2건, 갱신 62건
- `유입프로세스` 41건: 신규 5건, 갱신 36건
- `유출` 17건: 신규 0건, 갱신 17건

## 업로드 후 참고

- 일부 항목은 수임처와 자동 연결되지 않을 수 있으며, 이런 경우 별도로 연결 확인이 필요합니다.
- 수임처 명단 자체는 수정되지 않고, 유입·유입프로세스·유출 데이터만 반영됩니다.
