# 같은 사무실 · 공유 폴더로만 쓰기 (인터넷 공개 없음)

가능합니다. **인터넷에 올리지 않고**, 파일 서버(공유 폴더)에 두거나, **한 대 PC만** 서버를 돌리고 나머지는 브라우저로 접속하면 됩니다.

## 추천 구조

| 역할 | 설명 |
|------|------|
| **서버 역할 PC 1대** | `시작-사무실.bat` 실행 (또는 `npm run dev:lan`). 전원·실행 유지. |
| **다른 직원 PC** | 크롬/엣지에서 `http://서버PC의IP:3000` 또는 `http://서버PC이름:3000` 접속 |

- **서버 1대만** 실행하세요. 여러 PC에서 동시에 `npm run dev`를 돌리면 안 됩니다.
- 공유 폴더(`\\서버\공유\...`)에 그대로 두고 **그 경로에서 서버를 실행**할 수는 있지만, `node_modules`가 네트워크 드라이브에 있으면 **매우 느리거나 오류**가 날 수 있습니다.  
  **가능하면 서버 PC의 로컬 디스크**(예: `D:\apps\tax-analyzer`)에 복사해 두고 실행하는 것을 권장합니다. 공유 폴더는 **배포용 복사본 보관** 용도로만 써도 됩니다.

## 빠른 절차

1. **서버 PC**에서 프로젝트 폴더로 이동한 뒤 **`시작-사무실.bat`** 더블클릭  
2. 검은 창에 나오는 **IPv4 주소** 중 사무실 내부망(보통 `192.168.x.x`)을 확인  
3. **다른 PC** 브라우저 주소창에 `http://그IP:3000` 입력 (예: `http://192.168.0.15:3000`)

## Windows 방화벽

다른 PC에서 들어오지 않으면, **서버 PC**에서 포트 **3000** 인바운드를 허용해야 합니다.

- 관리자 PowerShell에서 저장소의 **`방화벽-3000포트-관리자로실행.ps1`** 실행  
  또는  
- Windows 보안 → 방화벽 → 고급 설정 → **인바운드 규칙** → 새 규칙 → TCP **3000** 허용

## HMR / 폰트 경고가 나올 때 (개발 모드)

동료 PC에서 접속할 때 개발자 콘솔에 차단 메시지가 나오면, **서버 PC** 프로젝트 루트에 `.env.local` 파일을 만들고 아래처럼 **접속하는 PC의 IP**를 쉼표로 넣은 뒤 서버를 한 번 재시작하세요.

```env
ALLOWED_DEV_ORIGINS=192.168.0.11,192.168.0.12
```

`next.config.ts`가 이 값을 읽어 `allowedDevOrigins`에 합칩니다.

## 프로덕션으로 더 안정적으로 (선택)

개발 서버(`dev`) 대신 한 번 빌드 후 실행하면 메모리·속도에 유리한 경우가 많습니다.

```bash
npm run build
npm run start:lan
```

`start:lan`은 `0.0.0.0:3000`에 바인딩합니다.

## 바로가기(.url)를 동료에게 줄 때

`로컬에서열기.url`은 **localhost**라서 다른 PC에서는 동작하지 않습니다.  
동료 PC에는 메모장으로 아래 내용의 **인터넷 바로가기** 파일을 만들어 주면 됩니다.

1. 새 텍스트 파일 → 내용만 다음 두 줄:

```ini
[InternetShortcut]
URL=http://192.168.0.여기서버IP:3000/
```

2. 파일 이름을 `종합소득세.url` 처럼 짓고 **확장자를 `.url`** 로 저장 (저장 형식: 모든 파일).

`192.168.0.여기서버IP`는 실제 서버 PC 주소로 바꿉니다.
