# 사이트가 안 열 때

## 1. 주소를 이렇게 열어 보세요

- **`http://127.0.0.1:3000/`** ← `localhost` 대신 이걸 권장합니다. (Windows에서 IPv6 때문에 막히는 경우가 있습니다.)
- **`로컬에서열기.url`** 도 위 주소로 맞춰 두었습니다.

## 2. 서버가 떠 있는지

- **`시작.bat`** 을 실행한 **검은 창을 닫지 마세요.** 닫으면 서버가 꺼집니다.
- 첫 실행은 `npm install` 때문에 **몇 분** 걸릴 수 있습니다. 그다음에야 포트 3000이 열립니다.

## 3. 포트 3000 충돌

다른 프로그램이 3000을 쓰면 Next가 실패합니다.

- PowerShell: `Get-NetTCPConnection -LocalPort 3000`  
- 해당 프로그램을 끄거나, 나중에 `package.json`의 `-p 3000`을 다른 포트로 바꿀 수 있습니다.

## 4. 방화벽 (다른 PC에서 접속할 때)

- 서버 PC에서 **`방화벽-3000포트-관리자로실행.ps1`** (관리자) 실행  
- 또는 **[docs/사내공유.md](./사내공유.md)** 참고

## 5. 그래도 안 되면

검은 창에 나온 **빨간 글 / npm ERR** 전체를 복사해 두면 원인 파악에 도움이 됩니다.
