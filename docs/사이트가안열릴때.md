# 사이트가 안 열 때

## 1. 주소를 이렇게 열어 보세요

- **`http://127.0.0.1:3000/`** 또는 **`http://localhost:3000/`** (둘 다 가능, `next.config`에 개발용 허용이 들어가 있습니다.)
- **`브라우저에서열기.url`** (상위 `종합소득세 분석` 폴더)은 **127.0.0.1** 로 열립니다.

**저장된 입력이 한쪽만 비어 있을 때:** 브라우저마다 주소가 다르면(`localhost` vs `127.0.0.1`) **저장소가 따로**입니다. 항상 **같은 주소**로 여세요.

## 2. 서버가 떠 있는지

- **`바로실행.bat`** 을 실행한 **검은 창을 닫지 마세요.** 닫으면 서버가 꺼집니다.
- 첫 실행은 `npm install` 때문에 **몇 분** 걸릴 수 있습니다. 그다음에야 포트 3000이 열립니다.

## 3. 포트 3000 충돌

다른 프로그램이 3000을 쓰면 Next가 실패합니다.

- PowerShell: `Get-NetTCPConnection -LocalPort 3000`  
- 해당 프로그램을 끄거나, `package.json`의 `-p 3000`을 다른 포트로 바꿀 수 있습니다.

## 4. 그래도 안 되면

검은 창에 나온 **빨간 글 / npm ERR** 전체를 복사해 두면 원인 파악에 도움이 됩니다.
