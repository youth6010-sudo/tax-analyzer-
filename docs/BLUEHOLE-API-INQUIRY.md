# 블루홀 API 연동 문의 템플릿 (본사 IT / 블루홀 운영팀)

부산지점 포털에서 블루홀 케이스를 조회·연동하기 위해 아래 항목 확인을 요청드립니다.

## 1. API 제공 여부

- REST API 또는 GraphQL 제공 여부
- Webhook(케이스 생성·상태 변경·담당 배정) 지원 여부
- 지점(부산)별 API 키 또는 OAuth 클라이언트 발급 가능 여부
- 개발/스테이징 환경 URL

## 2. 필요 scope

| 기능 | 용도 |
|------|------|
| `GET /case/{id}` | 포털 수임처 상세에서 케이스 미리보기 |
| `POST /case` (또는 거래처 생성) | 유입 확정 시 블루홀 케이스 자동 생성 |
| Webhook 수신 | 본사에서 케이스 변경 시 포털 체크리스트 자동 반영 |

## 3. 보안·정책

- iframe 임베드(`bluehole.world`) CSP 허용 가능 여부
- API 키 지점 단위 배포 가능 여부
- IP 화이트리스트(Vercel egress IP) 필요 여부
