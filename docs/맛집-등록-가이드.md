# 점심 맛집 자동 등록 가이드

가게명만 적으면 카카오 API로 **주소·카테고리·지도 링크·도보 시간**을 자동으로 채웁니다.

---

## 자주 헷갈리는 점: 「앱」이 없어도 됩니다

카카오가 말하는 **「애플리케이션(앱)」** 은 **스마트폰에 깔리는 프로그램이 아닙니다.**

| 카카오 말 | 실제 의미 |
|-----------|-----------|
| 애플리케이션 추가 | 개발자 사이트에 **프로젝트 이름 하나 등록** (2분) |
| 앱 키 | 그 프로젝트용 **비밀번호(API 키)** |
| Web 플랫폼 | `localhost` 주소만 적어 두면 됨 |

**필요한 것:** 카카오 계정 + 이름 `세무팀점심` 같은 **등록용 이름**  
**필요 없는 것:** 앱스토어 출시, APK/IPA, 카카오 로그인 연동, 서비스 URL 공개

우리는 PC에서 `npm run import:lunch` 한 번 돌릴 때만 API를 씁니다.  
웹사이트(Vercel)에 API 키를 넣을 필요도 **없습니다** (`.env.local`은 본인 PC만).

---

## 1. 카카오 REST API 키 발급 (무료)

### ① 카카오 개발자 가입
1. [Kakao Developers](https://developers.kakao.com) 접속
2. 카카오 계정으로 로그인

### ② 「애플리케이션」 등록 (실제 앱 X, 이름만)
1. 상단 **내 애플리케이션** → **애플리케이션 추가하기**
2. **앱 이름:** `세무팀점심` 또는 `tax-analyzer` (아무 이름)
3. **사업자명:** 본인 이름 또는 회사명 → **저장**

> **중요:** **테스트 앱**이 아닌 **일반 앱**으로 만드세요.  
> 테스트 앱은 Local API **하루 100건**만 제공됩니다. 일반 앱은 **하루 10만 건** 무료입니다.

### ③ REST API 키 복사
1. 만든 앱 클릭 → **앱 키** 탭
2. **REST API 키** 옆 **복사** (JavaScript 키가 아님)

### ④ 플랫폼 등록
1. **플랫폼** → **Web** → **Web 플랫폼 등록**
2. 사이트 도메인: `http://localhost:3000` (로컬 스크립트용으로 등록)

### ⑤ 카카오맵 API 사용 설정
1. **제품 설정** → **카카오맵** (또는 **API** 목록에서 **로컬**)
2. **활성화 설정** → **ON**

### ⑥ (선택) 유료 API
- 맛집 import 스크립트는 가게 수십~수백 곳 수준이면 **무료 한도로 충분**합니다.
- **유료 API**는 켜지 않아도 됩니다.

---

## 2. 사무실 좌표 구하기

도보 시간·가까운 순 정렬에 사용합니다.

1. [카카오맵](https://map.kakao.com) 에서 **사무실 위치** 검색
2. 사무실 위 **우클릭** → **이 위치가 궁금한가요?**
3. 아래에 나오는 **위도(lat), 경도(lng)** 확인  
   (또는 URL/개발자 도구에서 `y`=위도, `x`=경도)

---

## 3. 프로젝트 설정

프로젝트 루트에 `.env.local` 파일 생성 (git에 올리지 않음):

```env
KAKAO_REST_KEY=복사한_REST_API_키
OFFICE_LAT=37.5012
OFFICE_LNG=127.0396
OFFICE_LABEL=○○빌딩 3층
LUNCH_SEARCH_RADIUS=2000
```

| 변수 | 설명 |
|------|------|
| `KAKAO_REST_KEY` | REST API 키 (필수) |
| `OFFICE_LAT` | 사무실 위도 (권장) |
| `OFFICE_LNG` | 사무실 경도 (권장) |
| `OFFICE_LABEL` | `/lunch` 페이지에 표시할 문구 |
| `LUNCH_SEARCH_RADIUS` | 검색 반경(m), 기본 2000 |

`.env.example` 에도 같은 항목이 있습니다.

---

## 4. 맛집 목록 작성

```bash
copy data\lunch-list.example.txt data\lunch-list.txt
```

`data/lunch-list.txt` 예:

```text
# 한 줄에 하나
강남역 ○○국밥
△△짬뽕|역삼동 123
□□돈까스
```

- `#` 로 시작하는 줄은 주석
- `가게명|동네/주소` — 같은 이름 가게가 많을 때

---

## 5. 실행

```bash
npm run import:lunch
```

결과: `public/data/lunch-spots.json` 생성/갱신

- **자동 입력:** 이름, 카테고리, 태그, 도보 시간, 네이버/카카오 지도 URL, 주소 메모
- **직접 보완:** `priceRange`, `menuHints`, `notes`, `tags`
- **재실행 시:** 같은 가게명이면 위 수동 필드는 **유지**됩니다.

---

## 6. 배포

```bash
git add public/data/lunch-spots.json
git commit -m "chore: update lunch spots"
git push origin main
```

Vercel에 반영되면 `/lunch` 에서 바로 확인할 수 있습니다.

## API 요금 (참고)

| 항목 | 내용 |
|------|------|
| 카카오 Local API | **하루 10만 건 무료** (일반 앱) |
| 맛집 50곳 import | API **50번** → 무료 |
| 유료 전환 | 무료 초과 시 건당 약 0.5원 (별도 설정 필요) |

---

## 문제 해결

| 증상 | 해결 |
|------|------|
| `401` / `403` | REST API 키 확인, 카카오맵(로컬) API 활성화 |
| `429` | 일일 한도 초과 — 내일 재시도 또는 테스트 앱인지 확인 |
| 결과 없음 | `가게명\|동네` 형식으로 힌트 추가 |
| 엉뚱한 가게 | 카카오맵에서 정확한 상호 확인 후 목록 수정 |
