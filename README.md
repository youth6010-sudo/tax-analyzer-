# 종합소득세 신고서 분석 도구

## PC에서 쓰는 방법 (링크만 누르기)

1. **`시작.bat`** 을 더블클릭합니다. (잠시 뒤 브라우저가 **http://localhost:3000** 으로 열립니다.)
2. 이미 서버를 켜 둔 상태라면 **`로컬에서열기.url`** 만 더블클릭해도 같은 주소로 들어갑니다.

인터넷 공개 없이 **같은 사무실·공유 폴더**만 쓰려면 → **[docs/사내공유.md](./docs/사내공유.md)**  
**페이지가 안 열릴 때** → **[docs/사이트가안열릴때.md](./docs/사이트가안열릴때.md)**  
**GitHub + Vercel 배포** → **[docs/GITHUB-VERCEL-연결.md](./docs/GITHUB-VERCEL-연결.md)**

PDF 형식의 종합소득세 신고서를 업로드하여 업종별 단순경비율과 실제 소득율을 자동 비교 분석하는 웹 도구입니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| PDF 업로드 | 드래그 앤 드롭 또는 클릭으로 신고서 PDF 업로드 |
| 자동 케이스 판별 | 신고유형코드에 따라 CASE A/B 자동 구분 |
| 업종코드 매칭 | 추출된 업종코드로 단순경비율 자동 조회 |
| 소득율 계산 | 수입금액, 필요경비, 소득금액, 소득율 자동 계산 |
| 비교 분석 | 단순경비율 대비 실제 소득율 차이 표시 |

## 분석 케이스

- **CASE A**: 소득구분코드 30·40 + 신고유형코드 20 → 총수입금액 및 필요경비 명세서
- **CASE B**: 신고유형코드 12 → 표준손익계산서

## 계산 공식

- **소득금액** = 수입금액 합계 − 필요경비 합계
- **소득율 (B)** = (소득금액 ÷ 수입금액 합계) × 100
- **비용 비율** = (각 항목 ÷ 수입금액 합계) × 100
- **차이** = 실제 소득율(B) − 단순경비율 기준 소득율(100% − 단순경비율)

## 시작 방법

### 간편 실행
1. **`시작.bat`** (또는 **`시작하기.bat`**) 더블클릭 → 서버가 뜨고 약 8초 뒤 브라우저가 **http://localhost:3000** 으로 열립니다.  
2. 서버를 이미 켜 둔 경우에는 **`로컬에서열기.url`** 만 더블클릭하면 됩니다.
3. **같은 사무실 다른 PC**에서 접속하려면 **`시작-사무실.bat`** 과 **[docs/사내공유.md](./docs/사내공유.md)** 를 보세요.

### 수동 실행
```bash
npm run dev
```
브라우저에서 http://localhost:3000 접속

## 웹 배포 (인터넷 공개)

자세한 절차는 [docs/DEPLOY.md](./docs/DEPLOY.md)를 참고하세요.

- **Vercel**: GitHub 연결 후 자동 빌드·HTTPS URL 발급 (`vercel.json` 포함)
- **Docker**: `Dockerfile`, `docker-compose.yml`로 컨테이너 실행
- **Node 서버**: `npm run build` → `npm run start`

## 데이터 파일

- `public/industry_rates.json` — 2025년 귀속 업종코드별 경비율 (1,542개 업종)
- `data/industry_rates.json` — 샘플 구조 파일

## 주의사항

- **PDF 형식**: 텍스트가 포함된 PDF만 지원 (이미지 스캔본 불가)
- **데이터 정확도**: PDF 구조에 따라 파싱 결과가 다를 수 있음
- **최종 판단**: 세무 결정은 반드시 세무사와 상담
