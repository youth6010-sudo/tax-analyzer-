# 세무사랑 전표입력 지식베이스 (자동입력 에이전트용)

이 문서는 세무사랑(세무사랑2 / 세무사랑Pro) 전표입력 방법을 정리한 것으로,
agent.py가 화면을 보고 "어느 칸에 무엇을, 어떤 계정과목/구분으로" 입력할지 판단하는 근거로 사용한다.

출처: semulove.com(일반/매입매출전표 상세설명), WEHAGO 고객센터, smilesoft 매뉴얼,
세정코리아 경리실무 강의, 세무사신문(세무사랑Pro 활용 시리즈), 뉴젠솔루션 자료,
전산회계 표준 계정과목표(InTax, 네이버 세무사랑 블로그 등) 종합.

---

## 1. 메뉴 위치와 화면 구성

- **일반전표입력**: `회계 ▶ 전표관리 ▶ 일반전표입력`
  - 부가가치세 신고와 **무관한** 거래(일반 현금/이체 등).
- **매입매출전표입력**: `회계 ▶ 전표관리 ▶ 매입매출전표입력`
  - 세금계산서/계산서/현금영수증/**신용카드 매입·매출** 등 **부가세 신고 대상** 거래.
- 화면 구성: **상단 = 툴바(검색 F6, 코드도움 등) / 중단 = 전표 입력 행 / 하단 = 분개·도움박스**.
- 같은 비용이라도 적격증빙(세금계산서/현금영수증/카드)으로 **매입세액공제** 대상이면 매입매출전표입력에, 아니면 일반전표입력에 넣는다.

---

## 2. 일반전표입력 (커서는 각 칸 입력 후 Enter로 다음 칸 이동)

입력 순서: **월 → 일 → 구분 → 계정과목 → 거래처 → 적요 → 금액**

1. **월** : 2자리 (예 `06`)
2. **일** : 2자리 (예 `20`)
3. **구분(전표유형)**
   - `1` 출금(현금지출), `2` 입금(현금수입)
   - `3` 차변, `4` 대변 (대체전표)
   - `5` 결산차변, `6` 결산대변
4. **계정과목** : 코드 입력 시 과목명 자동. 모르면 과목명 앞 두 글자 입력 후 **F2**(코드도움)로 검색·선택.
5. **거래처(코드)** : 채권/채무 계정은 필수. 코드 모르면 **`+`키** → 거래처명 직접 입력 → Enter(코드 자동/신규등록). 일반 비용은 생략 가능.
6. **적요** : 거래 내용.
7. **금액** : 숫자. 금액란에서 **`+`키** = `000` 자동.

대체전표는 **차변(3) 합계 = 대변(4) 합계**가 맞아야 1개의 전표로 완성된다.

---

## 3. 매입매출전표입력 (부가세 대상)

상단에 부가세 자료(유형/공급가액/세액/거래처/전자여부 등)를 입력하고, **분개유형**을 고르면 하단 분개가 활성화된다.

### 3-1. 유형 코드
- 매출: `11`과세 · `12`영세 · `13`면세 · `14`건별(무증빙/간이) · `17`카과(카드과세) · `22`현과(현금영수증 과세)
- 매입: `51`과세 · `52`영세 · `53`면세 · `54`불공(매입세액불공제) · `57`카과(카드과세) · `61`현과(현금영수증 과세)
- 카드/현금영수증 거래는 보통 부가세 포함 총액을 공급가액란에 넣으면 공급가액·세액이 자동 분리(환경설정 기준).
- 세금계산서와 카드전표를 모두 받은 과세매입은 `51.과세`가 우선.

### 3-2. 분개유형
- `0` 분개없음 · `1` 현금 · `2` 외상 · `3` 혼합 · `4` 카드 · `5~7` 외상추가
- **혼합(3)**: 계정과목을 직접 지정/수정해야 할 때 (가장 범용).
- **카드(4)**: 카드결제 거래. 카드사를 별도 입력.

### 3-3. 신용카드 매입 처리(중요)
- 카드로 결제한 과세매입(매입세액공제 대상): 유형 **`57.카과`** + 분개 **`3.혼합`**
  - 차변: 비용계정(예 복리후생비 811) + **부가세대급금(135)**
  - 대변: **미지급금(253)**, 거래처는 **카드사**(가맹점 아님 — 미지급금 잔액관리 목적)
- 카드매입이지만 **불공제** 항목이면 일반전표입력에 입력(부가세 미반영).

---

## 4. 표준 계정과목 코드 (전산회계 기준 대표값)

실제 회사 코드는 다를 수 있으므로 화면에서 F2로 확인·선택하는 것이 안전하다.

### 자산/부채/결제수단
- `101` 현금 · `102` 당좌예금 · `103` 보통예금
- `135` 부가세대급금 · `255` 부가세예수금
- `251` 외상매입금 · `253` 미지급금 · `254` 예수금
- 개인사업자 대표 개인지출: 인출금(자본 차감) / 법인 대표 가지급금

### 판매비와관리비 (800번대, 본사/관리 비용)
- `801` 임원급여 · `802` 급여 · `803` 상여금 · `805` 잡금
- `811` 복리후생비(직원 식대·회식·경조사·4대보험 회사부담)
- `812` 여비교통비(출장·교통·주차·숙박·통행료)
- `813` 접대비(=기업업무추진비, 거래처 접대·선물·경조사)
- `814` 통신비 · `815` 수도광열비 · `817` 세금과공과 · `818` 감가상각비
- `819` 지급임차료 · `820` 수선비 · `821` 보험료 · `822` 차량유지비
- `824` 운반비 · `825` 교육훈련비 · `826` 도서인쇄비 · `827` 회의비
- `829` 사무용품비(문구류) · `830` 소모품비 · `831` 지급수수료
- `833` 광고선전비 · `848` 잡비
- (공장/제조 관련 비용은 500번대 사용)

## 5. 적요 → 계정과목 추정 가이드

| 거래 성격 | 추정 계정과목 |
| --- | --- |
| 직원 회식/식대/간식/경조사 | 복리후생비 (811) |
| 거래처 접대·미팅 식사·선물 | 접대비(기업업무추진비) (813) |
| 출장/교통/주차/대리운전 | 여비교통비 (812) |
| 사무용품(A4·필기구) | 사무용품비(829) 또는 소모품비(830) |
| 전화/인터넷/우편 | 통신비 (814) |
| 광고/홍보 | 광고선전비 (833) |
| 각종 수수료 | 지급수수료 (831) |

## 6. 주요 단축키

- **F2** 코드도움(계정과목·거래처 검색)
- **F3** 전표조회/수정(라인 더블클릭과 동일)
- **F4** 불러오기(고정자산 등)
- **F6** 저장 / 검색
- **F7** 취소·창닫기 (또는 카드매출 입력)
- **F8** 전표삭제 / (매입매출) 적요및카드매출 팝업
- **F11** 선택조회 · **Shift+F1** 중복전표검색 · **SF9** 일괄삭제 및 기타(코드변환)
- **`+`** 금액란 `000` 자동 / 거래처코드란 거래처명 직접입력
- **Enter** 직전 전표와 같은 값이면 해당 칸 복사 입력
- **Space**(금액란) 대차차액 자동조정(plug)

---

## 7. 한 건 처리 흐름 요약 (일반전표 대체분개 기준)

1. 월·일 입력
2. 구분 `3`(차변) → 비용 계정과목(F2 검색) → (필요시)거래처 → 적요 → 금액
3. 구분 `4`(대변) → 결제수단 계정(법인카드=미지급금 253 / 현금=현금 101) → 같은 금액
4. 차·대 합계 일치로 전표 완성 → 다음 거래 반복

---

## 8. 예시: 현재 보유 거래 권장 분개

- **역삼포차 120,000 (거래처 사장님 미팅 식사비, 개인카드)**
  → 거래처 접대이므로 **접대비(813)** 차변 / 결제수단 대변(개인카드면 인출금·가지급금, 법인카드면 미지급금 253)
- **알파문구 35,500 (A4·필기구, 현금영수증)**
  → **사무용품비(829)** 또는 소모품비(830) 차변 / 현금(101) 대변
  → 현금영수증 매입세액공제 대상이면 매입매출전표 `61.현과`로도 처리 가능
- **카카오T 대리운전 42,000 (야근 지방출장, 법인카드)**
  → **여비교통비(812)** 차변 / 미지급금(253, 카드사) 대변
  → 카드 과세매입이면 매입매출전표 `57.카과` + 분개 `3.혼합` 고려
